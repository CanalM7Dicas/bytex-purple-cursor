# ByteX Purple Cursor

Tema de cursores roxos para Windows, criado pelo Canal M7 Dicas. Também chamado de Nova Cursor durante o desenvolvimento.

## Instalar

Baixe `ByteX-Purple-Cursor-v1.0.0.zip` na página de versões, extraia o ZIP inteiro e abra `Install-Theme.bat`. Os arquivos da pasta `cursors` precisam permanecer ao lado dos scripts.

O instalador copia os cursores para o perfil do usuário, salva o tema atual e aplica o ByteX. Não precisa de acesso de administrador. O Windows pode mostrar um aviso antes de executar scripts baixados da internet; leia o código antes de prosseguir.

## Restaurar

Abra `Restore-Theme.bat`. Ele recupera o tema que estava ativo antes da primeira instalação. A cópia desse tema fica em `%LOCALAPPDATA%\ByteX Purple Cursor\previous-cursors.json` até a restauração. Se não houver cópia, o restaurador não altera os cursores.

## Código e arquivos

O ZIP de instalação contém somente os scripts e os 17 cursores usados pelo tema. Vetores SVG, imagens PNG e a página de visualização foram deixados fora da publicação porque não são necessários para instalar.
